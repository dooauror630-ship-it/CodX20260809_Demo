# 内置智能体待办清单

## 管理员 API 管理功能（待补齐）

状态：已记录，待后续开发。优先级：发布前必须完成。

当前缺口：模型供应商、API 地址、模型名称和 API Key 仍主要通过服务器环境变量配置，管理员无法在系统内维护；更换模型需要修改配置并重启网关。

计划范围：

- 管理员专属的“智能体 API 管理”页面。
- 支持维护供应商、API 地址、模型名称和 API Key。
- API Key 只在服务端保存，前端仅显示掩码，禁止写入聊天记录、浏览器存储和 Git。
- 提供连接测试和启用配置切换。
- 配置修改写入审计日志，并限制为系统管理员操作。
- 网关运行时重新加载配置；环境变量保留为首次启动和故障回退配置。
- 配置读取失败或模型不可用时，给出明确的业务提示，不暴露密钥和内部堆栈。

验收条件：

1. 非管理员访问接口和页面均返回无权限。
2. 管理员可以新增、修改、停用模型配置，并测试连接。
3. 切换配置后新建智能体会话使用新模型，已有会话按既有策略处理。
4. API Key 在接口响应、前端页面、日志和导出文件中均不明文出现。
5. 配置变更可追溯到操作人、时间、供应商和模型，但审计内容不包含密钥。
6. 环境变量回退、配置校验、权限、审计和网关重载均有自动化测试。
